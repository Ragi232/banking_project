# MY PYTHON BANK

A Python command-line banking system built to practice real-world Python programming.

## Features

* Customer login
* Admin login
* Create account
* Deposit money
* Withdraw money
* Check account balance
* Transaction history
* Transfer money
* Account statement
* Change PIN
* Edit account details
* Close account
* Search transactions
* Transaction IDs
* Transaction dates
* Transaction receipts
* Daily withdrawal limits
* Daily transfer limits
* Account blocking and unblocking
* Save accounts to a file
* Load accounts when the program starts

## Project Files

* `bank.py` - Main banking application
* `accounts.txt` - Stores account information and transactions
* `bank_backup.py` - Backup copy of the working bank program
* `receipts/` - Stores transaction receipt files
* `README.md` - Project documentation

## How to Run

Open the terminal inside the project folder and run:

```
python3 bank.py
```
